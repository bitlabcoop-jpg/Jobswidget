Jobs-Weisheit Widget (nativ, Kotlin)

1. Android Studio öffnen -> Open -> diesen Ordner wählen, Gradle-Sync abwarten.
2. Pixel 6a per USB anschließen (Entwickleroptionen + USB-Debugging an).
3. Grüner Run-Pfeil -> App wird installiert.
   Oder: Build > Build APK(s) und die APK aufs Handy kopieren.
4. Homescreen lange drücken -> Widgets -> "Jobs Weisheit" -> platzieren.
